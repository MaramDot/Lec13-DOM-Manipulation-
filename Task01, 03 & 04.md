**1. innerText:**

* بترجع النص الظاهر فقط للمستخدم
* بتتجاهل النص المخفي بـ CSS



const div=document.querySelector("#Task01");

console.log(div.innerText);



**outout** will be: Hello World





**2. textContent:**

* بترجع كل النص داخل العنصر
* حتى النص المخفي



console.log(div.textContent);



**outout** will be: Hidden Text Hello World





**3. innerHTML:**

* بترجع النص
* html



console.log(div.innerHTML);



**outout** will be: <span style="display:none;">Hidden Text</span>

&nbsp;               <b>Hello World</b>

**Task03**



<div id="box"></div>

----------------------------------------------

1. **appendChild():**

* يضيف عنصر واحد فقط
* ما بضيف نص



const box=document.querySelector("#box");



const p=document.createElement("p");

p.innerText="Paragraph";



box.appendChild(p);





**2.append():**

* يضيف أكثر من عنصر
* &nbsp;بضيف نص



box.append("Hello");



const btn=document.createElement("button");

box.append(btn,p);





**3.prepend():**

* يضيف بالبداية



box.prepend("Start");
